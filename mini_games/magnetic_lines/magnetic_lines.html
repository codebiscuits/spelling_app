WebGPU is not available

This toy draws with WebGPU, and this browser cannot start it.

To run it, use one of these:

  • Chrome or Edge 113+ on Windows, macOS or ChromeOS. WebGPU is on by default.
  • Chrome on Linux: enable chrome://flags/#enable-unsafe-webgpu, then restart. On some systems you also need --enable-features=Vulkan.
  • Firefox 141+ on Windows, or Firefox Nightly elsewhere with dom.webgpu.enabled set to true in about:config.
  • Safari 26+ on macOS 26 or iOS 26.

The page must also be served over http://localhost or https://. Some browsers block WebGPU on a plain file:// page.
